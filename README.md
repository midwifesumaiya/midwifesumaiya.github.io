# Sumaiya — Registered Midwife Portfolio

A responsive, static professional portfolio for Sumaiya, a Registered Midwife in Bangladesh. Hosted with GitHub Pages.

## Pages
- \`index.html\` — homepage and professional introduction
- \`about.html\` — background, values, education and registration
- \`portfolio.html\` — academic work, learning reflections and professional development categories
- \`cv.html\` — printable CV layout; use **Print or save as PDF** to export a PDF from your browser

## Technology
- Semantic HTML
- Shared CSS in \`assets/css/style.css\`
- Small vanilla JavaScript file in \`assets/js/main.js\`
- SVG favicon in \`assets/images/favicon.svg\`
- No build step, database or backend required

## Deployment
The site is configured for GitHub Pages. Changes merged or pushed to the configured publishing branch will deploy through the existing GitHub Pages workflow.

## Content maintenance
Before using the CV for applications, confirm education dates and all other details. Add only genuine experience, training and certificates. Add portfolio materials only when they are ready to share. Do not publish patient-identifying information or confidential clinical records.

## Search
The sitemap at \`/sitemap.xml\` includes all four HTML pages. Submit or re-submit it in Google Search Console after publishing and inspect individual URLs if needed. Sitemap submission does not guarantee indexing.
